Install

Homebrew (macOS & Linux)

brew tap use-tokesaver/tokensaver
brew install tokensaver

A prebuilt binary for macOS and Linux, Intel and ARM — no Go toolchain needed. Homebrew 7 refuses to load non-official taps until you trust them, so if it complains, run brew trust use-tokesaver/tokensaver and install again.

Windows, or without Homebrew

Download an archive from Releases (.zip on Windows, .tar.gz elsewhere) and put the tokensaver binary on your PATH.

Optional: Chrome

Chrome, Chromium, Brave or Edge installed in the usual place (or TOKENSAVER_CHROME=/path/to/chrome) lets tokensaver render JavaScript-only pages.
