Why tokensaver

Local & private

Runs on your machine as a stdio MCP server. Nothing is sent anywhere except the requests to URLs you ask for — no telemetry, no API keys, and it never calls an LLM itself.

No runtime dependencies

One Go binary. PDF extraction uses PDFium compiled to WebAssembly inside the binary. Chrome is used only if installed, for JS-only pages.

Fewer tokens

Clean Markdown or shrunk JSON, paged with an outline so your agent reads just the part it needs. Inspired by Microsoft MarkItDown, rebuilt in Go around one goal.

Install

Homebrew (macOS & Linux)

brew tap use-tokesaver/tokensaver
brew install tokensaver

On Windows, or not using Homebrew? Grab an archive from Releases.

Connect it to Claude Code

claude mcp add --scope user tokensaver -- tokensaver

Installing another way, or connecting Cursor, Claude Desktop, or another MCP client? See Docs → Install and Docs → Connect it to your agent. Once it is running, Docs → Usage shows what to ask for.
